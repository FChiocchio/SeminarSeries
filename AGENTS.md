# Project instructions

## Speaker dates and campus availability

- Whenever a speaker date is discussed for the first time, check that all ESCP
  campuses are available before proposing, offering, or confirming the date.
- Check the project records and any available campus calendars or schedules for
  conflicts. Do not assume that a date is available because one campus is free.
- If availability for every campus cannot be verified from the information
  available, tell Francesco explicitly before treating the date as confirmed.
- If a proposed date conflicts with an existing record, flag the conflict and
  ask which information should take precedence.
